# 🎮 Number Guessing Game

📌 About the Project

The Number Guessing Game is a beginner-friendly Python project where the computer generates a random number between 1 and 10, and the player tries to guess it.

The game provides hints if the guessed number is too high or too low, making it fun and interactive.

This project helped me learn Python fundamentals such as variables, user input, conditional statements, and random number generation.

🎯 How It Works

1️⃣ The computer generates a random number between 1 and 10

2️⃣ The player enters a guess

3️⃣ The program compares the guess with the secret number

4️⃣ The game displays:

- 🎊 Congratulations, You Won!
- 🚀 Too High
- 😱 Too Low
